Boogle part 0 is the previous step for the completion of the whole Boogle then Halma project. 
This first part contains
- The .txt file of the Boogle board, a 4x4 board in this case, with 4 letters
per row separated by spaces.
- The .py file with all the written code using basic Python structures (list, set, dict) and some functions (len, range, strip),
  as well as the 3 main functions:
    - loadBoard(filename) -> reads a board file and returns it as a 2D list.
    - printBoard(board) -> prints the NxN board. Receives a 2D list and prints the       board with letters separated by spaces.
    - possibleMoves(position, board) -> returns as form of coordinates the valid adjacent coordinates from a position.
